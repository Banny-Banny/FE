# Feature Specification: 관리자 알림 푸시 수신

**Feature Branch**: `004-push-notification`  
**Created**: 2025-01-27  
**Status**: Draft  
**Input**: User description: "어드민 페이지에서 관리자가 사용자들한테 알림을 발송하는 api야. 현재 어드민 페이지에는 api가 연동되어 있는 상태고, 메시지 발송은 되는 상태야. 이제 관리자가 웹에서 메시지를 발송하면 앱에서 사용자가 알림으로 받는 기능만 생기면 돼."

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 관리자 알림 푸시 수신 (Priority: P1)

사용자가 앱을 사용 중이거나 백그라운드에 있을 때, 관리자가 웹에서 발송한 알림을 푸시 알림으로 받을 수 있습니다.

**Why this priority**: 관리자가 사용자에게 중요한 공지나 메시지를 전달할 수 있는 핵심 기능으로, 이 기능이 없으면 관리자 알림 발송 기능의 목적을 달성할 수 없습니다.

**Independent Test**: 관리자가 어드민 페이지에서 알림을 발송하면, 대상 사용자의 앱에서 푸시 알림이 수신되는지 확인할 수 있습니다. 앱이 포그라운드, 백그라운드, 종료 상태 모두에서 테스트할 수 있습니다.

**Acceptance Scenarios**:

1. **Given** 사용자가 앱을 실행 중이고 푸시 알림 권한이 허용된 상태, **When** 관리자가 해당 사용자에게 알림을 발송하면, **Then** 사용자의 앱에서 푸시 알림이 수신됩니다.
2. **Given** 사용자가 앱을 백그라운드로 보낸 상태, **When** 관리자가 해당 사용자에게 알림을 발송하면, **Then** 사용자의 기기에서 푸시 알림이 표시됩니다.
3. **Given** 사용자가 앱을 완전히 종료한 상태, **When** 관리자가 해당 사용자에게 알림을 발송하면, **Then** 사용자의 기기에서 푸시 알림이 표시됩니다.
4. **Given** 사용자가 푸시 알림을 수신한 상태, **When** 알림을 탭하면, **Then** 앱이 열리고 알림 화면으로 이동합니다.

---

### User Story 2 - 관리자 알림 목록 표시 (Priority: P1)

사용자가 관리자로부터 받은 알림을 알림 목록에서 확인할 수 있습니다.

**Why this priority**: 사용자가 받은 알림을 나중에 다시 확인할 수 있어야 하므로, 알림 목록에 표시되는 것은 필수 기능입니다.

**Independent Test**: 관리자가 알림을 발송한 후, 사용자의 앱에서 알림 목록 화면을 열어 해당 알림이 표시되는지 확인할 수 있습니다.

**Acceptance Scenarios**:

1. **Given** 사용자가 관리자 알림을 푸시로 수신한 상태, **When** 알림 목록 화면을 열면, **Then** 해당 알림이 목록에 표시됩니다.
2. **Given** 사용자가 관리자 알림을 수신한 상태, **When** 알림 목록을 확인하면, **Then** 알림의 제목과 내용이 올바르게 표시됩니다.
3. **Given** 사용자가 관리자 알림을 수신한 상태, **When** 알림 목록을 확인하면, **Then** 알림이 읽지 않은 상태로 표시됩니다.

---

### User Story 3 - 관리자 알림 탭 시 화면 이동 (Priority: P2)

사용자가 관리자 알림을 탭했을 때 적절한 화면으로 이동합니다.

**Why this priority**: 사용자가 알림을 통해 관련 정보를 빠르게 확인할 수 있도록 하는 기능으로, 사용성 향상에 중요합니다.

**Independent Test**: 관리자 알림을 탭하여 알림 화면으로 이동하는지 확인할 수 있습니다.

**Acceptance Scenarios**:

1. **Given** 사용자가 관리자 알림을 수신한 상태, **When** 알림을 탭하면, **Then** 앱이 열리고 알림 화면으로 이동합니다.
2. **Given** 사용자가 앱이 실행 중인 상태에서 관리자 알림을 탭하면, **Then** 알림 화면으로 이동합니다.

---

### Edge Cases

- **푸시 알림 권한이 거부된 경우**: 사용자에게 알림 권한이 필요하다는 안내를 표시하고, 설정 화면으로 이동할 수 있는 옵션을 제공합니다.
- **앱이 완전히 종료된 상태에서 알림 수신**: 알림을 탭하면 앱이 실행되고 알림 화면으로 이동합니다.
- **네트워크 연결이 없는 상태에서 알림 수신 시도**: 백엔드에서 푸시 알림 서비스를 통해 발송하므로, 네트워크가 복구되면 알림이 수신됩니다.
- **동일한 사용자에게 여러 알림이 동시에 발송된 경우**: 각 알림이 개별적으로 수신되고 알림 목록에 모두 표시됩니다.
- **알림 발송 후 사용자가 푸시 토큰을 변경한 경우**: 새로운 토큰이 등록되면 이후 알림은 새 토큰으로 수신됩니다.
- **알림 수신은 되었으나 알림 목록에 표시되지 않는 경우**: 알림 목록을 새로고침하면 표시됩니다 (기존 알림 목록 새로고침 기능 활용).

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 시스템은 관리자가 발송한 알림을 앱에서 푸시 알림으로 수신할 수 있어야 합니다.
- **FR-002**: 시스템은 관리자 알림을 수신했을 때 알림 목록에 자동으로 추가해야 합니다.
- **FR-003**: 시스템은 관리자 알림의 제목과 내용을 알림 목록에 올바르게 표시해야 합니다.
- **FR-004**: 시스템은 관리자 알림을 탭했을 때 알림 화면으로 이동해야 합니다.
- **FR-005**: 시스템은 관리자 알림 수신 시 기기의 알림 표시 기능을 통해 사용자에게 알림을 표시해야 합니다 (앱이 백그라운드이거나 종료된 상태).
- **FR-006**: 시스템은 관리자 알림 수신 시 앱이 포그라운드에 있을 때도 알림을 표시해야 합니다.
- **FR-007**: 시스템은 관리자 알림의 타입(SYSTEM)을 올바르게 인식하고 처리해야 합니다.
- **FR-008**: 시스템은 관리자 알림 수신 시 알림 목록을 자동으로 새로고침해야 합니다 (기존 알림 목록 새로고침 기능 활용).

### Key Entities *(include if feature involves data)*

- **관리자 알림 (Admin Notification)**: 관리자가 웹에서 발송한 알림. 제목(title), 내용(content), 타입(type: SYSTEM), 대상 사용자(userId) 등의 속성을 가집니다.
- **푸시 알림 (Push Notification)**: 기기로 전송되는 알림 메시지. 제목, 내용, 데이터(타입 등)를 포함합니다.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 관리자가 알림을 발송한 후 10초 이내에 대상 사용자의 앱에서 푸시 알림이 수신됩니다 (성공률 95% 이상).
- **SC-002**: 사용자가 관리자 알림을 수신한 후 알림 목록 화면을 열면 해당 알림이 표시됩니다 (성공률 100%).
- **SC-003**: 사용자가 관리자 알림을 탭하면 2초 이내에 알림 화면으로 이동합니다.
- **SC-004**: 앱이 포그라운드, 백그라운드, 종료 상태 모두에서 관리자 알림을 정상적으로 수신합니다 (각 상태별 성공률 95% 이상).
- **SC-005**: 관리자 알림 수신 후 알림 목록이 자동으로 새로고침되어 최신 상태를 유지합니다 (성공률 100%).

## Assumptions

- 백엔드에서 관리자가 알림을 발송하면, 백엔드가 푸시 알림 서비스를 통해 사용자의 기기로 푸시 알림을 발송합니다.
- 백엔드에서 발송하는 푸시 알림의 데이터 구조에 알림 타입(type: SYSTEM)이 포함됩니다.
- 백엔드에서 발송하는 푸시 알림의 데이터 구조에 알림 ID가 포함되어 알림 목록과 매칭할 수 있습니다.
- 사용자의 푸시 토큰이 이미 백엔드에 등록되어 있습니다.
- 앱의 기존 푸시 알림 수신 인프라를 활용합니다.
- 앱의 기존 알림 목록 조회 기능을 활용합니다.
- 관리자 알림의 타입은 "SYSTEM"입니다 (API 문서 기준).
- 관리자 알림을 탭했을 때는 기본적으로 알림 화면으로 이동합니다.
- 알림 목록 자동 새로고침은 기존 알림 수신 메커니즘을 통해 처리됩니다.
