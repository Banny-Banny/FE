                   - onBack?: () => void (선택) - 뒤로가기 핸들러

                     - CRITICAL: 헤더 컴포넌트는 순수 UI만 담당하며, 비즈니스 로직은 포함하지 않음

                     - CRITICAL: 헤더 컴포넌트는 순수 UI만 담당하며, 비즈니스 로직은 포함하지 않음

                   - CRITICAL: onBack 핸들러는 각 페이지에서 정의하여 전달함

                   - react-native-remix-icon 사용
                   - CRITICAL: 각 아이콘의 onPress 핸들러는 각 페이지에서 정의하여 전달함
                   - CRITICAL: 헤더 컴포넌트는 순수 UI만 담당하며, 비즈니스 로직은 포함하지 않음

                   - showBorder?: boolean
