핵심요구사항) 공통 버튼 시스템 구현을 step-by-step으로 구현하고, 적용 결과를 체크리스트로 반환할 것.

            1) 라이브러리 조건
                - UI Framework: React Native 기본 컴포넌트 사용
                - Pressable 또는 TouchableOpacity 사용
                - 아이콘: 이미 설치되어있는 react-native-remix-icon 사용
                - 애니메이션: press 상태 시각적 피드백 제공 (선택사항)

            2) 버튼 종류 (피그마 기준)
                1. 단일 버튼 (Button)
                   - 크기: L(64px), M(56px), S(48px) - height 기준
                   - Variant:
                     - primary: 검은색 배경 (활성화 상태)
                     - secondary: 회색 배경 (비활성화 상태)
                     - outline: 흰색 배경 + 검은색 테두리 + 아이콘 (공유 등)
                   - 텍스트 라벨 (필수)
                   - 아이콘 (선택) - 텍스트 왼쪽 또는 단독
                   - 전체 너비 또는 고정 너비

                2. 듀얼 버튼 (DualButton)
                   - 취소 버튼 (왼쪽) + 확인 버튼 (오른쪽)
                   - 취소: secondary variant
                   - 확인: primary variant
                   - 동일한 크기 (L/M/S)
                   - 버튼 간격: 피그마에서 확인
                   - 용도: 바텀시트_버튼, 모달_버튼

            3) 디자인 시스템 (피그마 기준)
                CRITICAL: 각 버튼 노드를 반드시 확인하여 아래 값을 가져올 것

                1. 단일 버튼 스타일 - 피그마에서 확인 후 고정
                   Size L (height: 64px)
                   - primary:
                     - backgroundColor: 피그마 확인 (Colors 매칭)
                     - textColor: 피그마 확인 (Colors 매칭)
                     - borderRadius: 피그마 확인
                     - paddingHorizontal: 피그마 확인
                   - secondary:
                     - backgroundColor: 피그마 확인 (Colors 매칭)
                     - textColor: 피그마 확인 (Colors 매칭)
                     - borderRadius: 피그마 확인
                     - paddingHorizontal: 피그마 확인
                   - outline:
                     - backgroundColor: 피그마 확인 (Colors 매칭)
                     - textColor: 피그마 확인 (Colors 매칭)
                     - borderWidth: 피그마 확인
                     - borderColor: 피그마 확인 (Colors 매칭)
                     - borderRadius: 피그마 확인
                     - paddingHorizontal: 피그마 확인

                   Size M (height: 56px)
                   - primary, secondary, outline: L과 동일 속성 (크기만 다름)

                   Size S (height: 48px)
                   - primary, secondary, outline: L과 동일 속성 (크기만 다름)

                2. 듀얼 버튼 스타일 - 피그마에서 확인 후 고정
                   - 버튼 간격(gap): 피그마 확인
                   - 각 버튼 너비: flex: 1 (동일 너비)
                   - 왼쪽(취소): secondary variant
                   - 오른쪽(확인): primary variant

                3. 텍스트 스타일 - 피그마에서 확인
                   - fontSize: 피그마 확인 후 Typography에서 매칭
                   - fontWeight: 피그마 확인 후 Typography에서 매칭
                   - letterSpacing: 피그마 확인 (있다면)

                4. 아이콘 스타일 - 피그마에서 확인
                   - size: 피그마 확인
                   - color: textColor와 동일
                   - position: 텍스트 왼쪽 (marginRight 적용)

            4) Button 컴포넌트 구현
                1. Props 정의 (ButtonProps)
                   - label: string (필수) - 버튼 텍스트
                   - variant?: 'primary' | 'secondary' | 'outline' (선택, 기본값: 'primary')
                   - size?: 'L' | 'M' | 'S' (선택, 기본값: 'L')
                   - icon?: string (선택) - react-native-remix-icon 아이콘 이름
                   - iconPosition?: 'left' | 'only' (선택, 기본값: 'left')
                   - fullWidth?: boolean (선택, 기본값: true)
                   - disabled?: boolean (선택, 기본값: false)
                   - onPress: () => void (필수)

                2. 컴포넌트 구조
                   - Pressable 또는 TouchableOpacity 사용
                   - Constants에 정의한 스타일 적용
                   - props에 따라 동적 스타일 적용
                   - disabled 상태 처리
                   - press 상태 시각적 피드백

                3. 아이콘 렌더링
                   - iconPosition='only': 아이콘만 표시 (텍스트 숨김)
                   - iconPosition='left': 아이콘 + 텍스트
                   - icon이 없으면: 텍스트만

            5) DualButton 컴포넌트 구현
                1. Props 정의 (DualButtonProps)
                   - cancelLabel: string (필수) - 취소 버튼 텍스트
                   - confirmLabel: string (필수) - 확인 버튼 텍스트
                   - size?: 'L' | 'M' | 'S' (선택, 기본값: 'L')
                   - cancelDisabled?: boolean (선택, 기본값: false)
                   - confirmDisabled?: boolean (선택, 기본값: false)
                   - onCancelPress: () => void (필수)
                   - onConfirmPress: () => void (필수)

                2. 컴포넌트 구조
                   - 2개의 Button 컴포넌트를 가로로 배치
                   - 왼쪽: variant='secondary'
                   - 오른쪽: variant='primary'
                   - gap: Constants에 정의한 DUAL_BUTTON_GAP 사용
                   - 각 버튼: flex: 1 (동일 너비)

            6) Props/Config 타입 정의
                1. ButtonProps 타입
                   - label: string
                   - variant?: 'primary' | 'secondary' | 'outline'
                   - size?: 'L' | 'M' | 'S'
                   - icon?: string
                   - iconPosition?: 'left' | 'only'
                   - fullWidth?: boolean
                   - disabled?: boolean
                   - onPress: () => void

                2. DualButtonProps 타입
                   - cancelLabel: string
                   - confirmLabel: string
                   - size?: 'L' | 'M' | 'S'
                   - cancelDisabled?: boolean
                   - confirmDisabled?: boolean
                   - onCancelPress: () => void
                   - onConfirmPress: () => void
