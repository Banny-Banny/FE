핵심요구사항) 알림이 꺼져있을 때: expo-image의 Image 컴포넌트로 assets/icons/unnotification.png 사용 (style: notificationOffIcon, 24x24) - mypage header는 24x24 사용
핵심요구사항) handleNotificationPress 함수에서 토글 기능과 알림 화면 이동 기능을 모두 처리 (토글 후 알림 화면으로 이동하거나, 토글만 수행)
핵심요구사항) handleToggleNotification 함수로 알림 상태 토글 및 실제 알림 설정 API 호출 준비 (TODO 주석)
핵심요구사항) accessibilityLabel을 상태에 따라 동적으로 변경 ('알림 켜기' / '알림 끄기')
핵심요구사항) styles.ts에 notificationOffIcon 스타일 추가 (width: 24, height: 24) - mypage header는 24x24 사용
핵심요구사항) 알림 배지는 토글 기능과 독립적으로 유지 (알림 개수 표시용)

조건-공통컴포넌트-재검토) 현재 mypage header와 notification header는 유사한 구조를 가지고 있으나, 세부 스타일과 기능이 다름
조건-공통컴포넌트-재검토) mypage header 특징:
  - 알림 아이콘: 24x24, 배지 있음 (알림 개수 표시), 토글 기능 + 알림 화면 이동 기능
  - X 버튼: 32x32, backgroundColor: Colors.whiteGrey[500], borderRadius: BorderRadius.xl (20)
  - height: 73px, padding 없음
  - 타이틀: "마이페이지" (Typography.header.h1)
  - 서브타이틀 없음
  - borderLine: absolute position으로 화면 양끝까지 확장
조건-공통컴포넌트-재검토) notification header 특징:
  - 알림 아이콘: 20x20, 배지 없음, 토글 기능만
  - X 버튼: 40x40, backgroundColor 없음, borderRadius: BorderRadius.xl (20)
  - height: paddingVertical 32px, paddingHorizontal 24px
  - 타이틀: "알림" (Typography.header.h5)
  - 서브타이틀 있음 ("새 알림 3개", Typography.body.body11)
  - borderBottomWidth로 border 처리
조건-공통컴포넌트-재검토) 공통 컴포넌트 추출 가능성 분석:
  - 알림 아이콘 버튼: 토글 기능, 배지 옵션, 크기 옵션(20/24)으로 추출 가능하나, 현재는 각각 구현
  - X 버튼: 크기(32/40), 스타일 옵션으로 추출 가능하나, 현재는 각각 구현
  - 아이콘 컨테이너: gap 속성으로 간격 처리, 구조 유사하나 현재는 각각 구현
  - 전체 헤더: 레이아웃 구조와 스타일 차이가 커서 완전한 공통화는 어려움
조건-공통컴포넌트-재검토) 현재는 공통 헤더 컴포넌트가 없으므로, 각각 독립적으로 구현하되 향후 공통 컴포넌트 추출을 고려하여 구조를 유지할 것
조건-공통컴포넌트-재검토) 향후 공통화 고려사항:
  - commons/components/header-icon-button: 알림 아이콘 버튼 (토글, 배지, 크기 옵션)
  - commons/components/close-button: X 버튼 (크기, 스타일 옵션)
  - commons/components/icon-container: 아이콘 컨테이너 (gap 옵션)
조건-공통컴포넌트-재검토) commons/components/timecapsule-header는 다른 구조(뒤로가기 버튼 왼쪽, 제목 중앙)이므로 재사용 불가

구현단계)
1. index.tsx: JSX 구조만 작성 (View, Text 등 기본 컴포넌트 사용)
2. styles.ts: StyleSheet.create()로 모든 스타일 선언
3. 피그마 디자인과 1:1 대응되도록 레이아웃 구현 (소수점 값 반올림 필수)

6. expo-image의 Image 컴포넌트 사용 (알림 꺼짐 상태, unnotification.png, 24x24)
7. useState로 알림 토글 상태 관리 및 handleToggleNotification, handleNotificationPress 함수 구현
8. position-absolute는 borderLine 등 필수적인 경우에만 사용 (화면 양끝까지 확장)
9. 마이페이지 index.tsx에 Header import 및 렌더링 추가
