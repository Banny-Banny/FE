핵심요구사항) 아래의 기능 상세를 따를 것
1. 탭 시스템: '직접 녹음'과 '파일 업로드' 두 가지 모드를 제공함.
  1-1) '직접 녹음'
    - expo-av 를 사용하여 구현
    - 녹음 시간 타이머(0:00 형식)와 시작/중지 버튼을 포함함
    - 녹음 중 중지 시 S3에 바로 올리지 말고, 로컬 URI 상태로 보관
  1-2) '파일 업로드'
    - 파일 업로드 시, 바로 S3에 올리지 말고, 로컬 URI 상태로 보관
  1-3) 미리보기
    - 보관된 로컬 URI를 사용해 사용자가 녹음 내용을 다시 들어볼 수 있는 미리보기 UI를 제공
  1-4) 업로드 트리거
    - 실제 업로드(presign - S3 - complete : useMediaUpload)는 사용자가 egg-form에서 '숨기기' 버튼을 확정적으로 눌렀을 때만 실행하거나, 부모 폼의 제출 시점에 맞춰 실행될 수 있도록 할 것

2. 구현 로직 (hooks 분리)
  2-1) 로직 분리
    - hooks/useAudioRecorder.ts는 녹음과 로컬 URI 생성만 담당하고, API 호출은 전경 hooks/useMediaUpload.ts에서 진행
  2-2) API
    - axios를 사용하여, 백엔드 규격에 따라 음원은 반드시 type: "AUDIO"로 요청
  2-3) 에러 핸들링
    - 업로드 실패 시 사용자에게 알림을 주고, 로컬 파일은 유지하여 재시도 할 수 있게 함
