            - 두 개의 기능 소개 카드 (지도에서 추억 숨기기, 친구와 함께)
            - 하단 일러스트 이미지
            - 카카오 로그인 버튼 ("카카오로 시작하기")
            - 하단 저작권 표시 ("© 2025 타임캡슐")

사전분석단계)
1. package.json 확인하여 사용 가능한 라이브러리 분석
2. 피그마 구조 전체 분석 (레이아웃 → 섹션 → 컴포넌트 순)
3. commons/constants/color.ts의 색상 토큰 목록 확인
4. commons/constants/typography.ts의 타이포그래피 토큰 목록 확인
5. 공통 컴포넌트 목록 확인 및 재사용 가능 여부 판단
6. Figma MCP에서 제공된 이미지 에셋 확인 및 사용 방법 파악

==============================================

구현단계)
1. index.tsx: JSX 구조만 작성 (View, Text, Image 등 기본 컴포넌트 사용)
2. styles.ts: StyleSheet.create()로 모든 스타일 선언
3. 피그마 디자인과 1:1 대응되도록 레이아웃 구현
4. 토큰 기반 색상/타이포그래피만 사용
5. Figma MCP에서 제공된 이미지 URL은 Image 컴포넌트의 source로 직접 사용
6. 절대 위치 지정이 필요한 요소는 position: 'absolute' 사용
