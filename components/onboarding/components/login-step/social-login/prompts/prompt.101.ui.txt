사전분석단계)
1. package.json 확인하여 사용 가능한 라이브러리 분석
2. 피그마 구조 전체 분석 (레이아웃 → 섹션 → 컴포넌트 순)
3. commons/constants/color.ts의 Colors 토큰 목록 확인
4. commons/constants/typography.ts의 Typography 토큰 목록 확인
5. 공통 컴포넌트 목록 확인 및 재사용 가능 여부 판단
   - commons/components/button: 버튼 컴포넌트 사용 가능 (필요시)
   - commons/components/dual-button: 취소/동의 버튼 쌍 사용 가능 (필요시)
   - 기존 SocialLogin 컴포넌트의 props 인터페이스 확인 및 유지
   - 현재는 독립 구현, 향후 공통 컴포넌트 추출 고려

==============================================

구현단계)
1. index.tsx: JSX 구조만 작성 (View, Text 등 기본 컴포넌트 사용)
2. styles.ts: StyleSheet.create()로 모든 스타일 선언
3. 피그마 디자인과 1:1 대응되도록 레이아웃 구현
4. 토큰 기반 색상/타이포그래피만 사용
5. react-native-remix-icon의 Icon 컴포넌트 사용 (필요시)
6. **소수점 값 반올림**: 모든 스타일 속성의 소수점 값은 반올림하여 정수로 변환
7. 버튼이 필요한 경우 Button 또는 DualButton 공통 컴포넌트 사용 (직접 구현 금지)
8. 기존 SocialLogin 컴포넌트의 props 인터페이스 유지 (isLoading: boolean, onKakaoLogin: () => void, onEmailLogin: () => void)
9. Colors, Typography는 @/commons/constants에서 import하여 사용
10. Button, DualButton은 @/commons/components/button, @/commons/components/dual-button에서 import하여 사용
