구현 결과를 체크리스트로 반환할 것.

==============================================

조건-커서룰) 아래의 커서룰을 적용하여 작업하고, 이 작업이 끝나면 해당 rules 적용 결과를 체크리스트로 반환할 것.
            - @01-common.mdc
            - @04-func.mdc
            - @project-structure.mdc

조건-파일경로) 구현될 TSX 파일경로: FE/components/map/components/egg-slot/index.tsx
조건-파일경로) 구현될 CSS 파일경로: FE/components/map/components/egg-slot/styles.ts
조건-파일경로) 구현될 hooks 파일경로: FE/components/map/components/egg-slot/hooks 내부

조건-http) 설치되어 있는 'axios'를 사용할 것.
조건-상태 관리) 프로젝트에 세팅된 `react-provider` (React Query 등) 활용.

==============================================

핵심요구사항) 아래의 기능 상세를 따를 것
1. API 명세 (GET /api/capsules/slots)
  - **Endpoint**: `{API_BASE_URL}/api/capsules/slots`
  - **Header**: `Authorization: Bearer <JWT>`
  - **Response 200**:
    ```json
  {
    "totalSlots": number, (기본 슬롯은 최대 3개임. 이후, 추가 구매나 이벤트를 통해 증가가능하게 설계)
    "usedSlots": number,
    "remainingSlots": number
  }```

2. 구현 로직 (hooks 분리)
  - API 통신 로직은 반드시 hooks 폴더 내의 커스텀 훅으로 분리할 것 (04-func.mdc 규칙).
  - axios를 사용하여 통신하고, 에러 처리 로직을 포함할 것.
  - egg-slot을 누르면 egg-slot-modal에 결과값을 넘겨줘서 egg-slot-modal의 값에도 반영시킬 것.
