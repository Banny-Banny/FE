==============================================

핵심요구사항) 아래의 기능 상세를 따를 것
1. API 명세 (GET /api/capsules)
  - **Endpoint**: `{API_BASE_URL}/api/capsules?lat={lat}&lng={lng}&radius_m={radius_m=300}&limit={limit}`
  - **Header**: `Authorization: Bearer <JWT>`
  - **Query**: lat, lng (필수), radius_m(기본 300, 10~5000), limit(기본 50, ≤200), cursor(현재 미사용), include_locationless?, include_consumed?

  - response : { items: [{ id, title, content?, open_at, is_locked, view_limit, view_count, can_open, latitude, longitude, distance_m?, media_types, media_urls, product? }], page_info: null }

2. 구현 로직 (hooks 분리)
  - API 통신 로직은 반드시 hooks 폴더 내의 커스텀 훅으로 분리할 것 (04-func.mdc 규칙).
  - axios를 사용하여 통신하고, 에러 처리 로직을 포함할 것.
  - response를 받은 latitude, longitude를 기반으로 마커를 표시할 것
  - 이때 마커는 response의 데이터 들을 모두 가지고 있을 것. 이를 마커 누르면 콘솔에 찍히게 할 것.
