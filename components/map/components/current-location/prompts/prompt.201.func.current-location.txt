==============================================

핵심요구사항) 아래의 기능 상세를 따를 것
1. KaKao Local API
  - 사용자의 현재 위도/경도가 확보되면 카카오 로컬 API(https://dapi.kakao.com/v2/local/geo/coord2address.json)를 호출해 행정 구역 주소를 가져올 것.
  - Headers: Authorization: KakaoAK ${process.env.EXPO_PUBLIC_KAKAO_REST_API_KEY}
  - 변환된 주소(예: 서울특별시 강남구)를 화면 상단 UI에 표시할 것.

2. 구현 로직
  - hooks로 분리하되, map-view에서 받은 현재 lat와 lng를 기반으로 hook이나 props를 받아서 작동시킬 것.
  - 현재 존재하는 mock 데이터는 삭제시킬 것.
