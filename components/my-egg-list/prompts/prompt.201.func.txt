핵심요구사항) 아래의 기능 상세를 따를 것(step-by-step)

1. 데이터 페칭
  1-1) API
    - GET /api/capsules/my-eggs?type={type}&sort={sort}
    - type의 enum은 PLANTED | FOUND 로 필수 값.
    - sort의 enum은 LATEST | OLDEST 로 필수 값 아님

2. 데이터 바인딩
  1-1) type
    - 응답받은 type={PLANTED} 값을 기반으로 심은 알에 매칭 시킬 것.
    - 응답받은 type={FOUND} 값을 기반으로 발견한 알에 매칭 시킬 것.
  2-2) sort
    - 응답받은 sort 값을 기반으로 필터를 통해 정렬시킬 것.
  2-3) 데이터 바인딩
    - 기존에 존재하던 MOCK_DATA를 삭제시키고, 데이터를 바인딩 시킬 것.
