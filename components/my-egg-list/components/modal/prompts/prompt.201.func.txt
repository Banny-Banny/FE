1. 데이터 페칭
  1-1) API
    - GET /api/capsules/{id}/detail
    - id의 경우 이스터에그 id임

2. 데이터 바인딩 
  - 기존에 존재하던 MOCK_DATA를 삭제시키고, 데이터 바인딩을 적절히 할 것

  2-1) type: "FOUND"의 경우
    - 응답받은 데이터 title, message, imageMediaId, audioMediaId, videoMediaId, location.latitude, location.longitude, author.nickname, author.profileImg, createdAt 데이터를 활용하여 적절히 데이터 바인딩 할 것.
    - 이때, mediaId로 반환 받는 경우 api/media/{id}/url을 활용해서 이미지를 가져와 띄울 것
    - location.latitude와 location.longitude를 활용해서, useKakaoAddress를 훅을 활용해 string 주소로 띄워줄 것
    - 이전에 명시해둔 모든 데이터를 적절하게 배치시킬 것

  2-3) type: "PLANTED"의 경우
