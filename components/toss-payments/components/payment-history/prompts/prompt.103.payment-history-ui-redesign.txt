작업 순서

1. 피그마 디자인 분석
   - TalkToFigma 플러그인으로 피그마 디자인 읽기
   - 결제 내역 목록 화면 디자인 확인
     * 전체 레이아웃 구조
     * 필터 탭 디자인 (있는 경우)
     * 결제 카드 디자인
     * 빈 화면 디자인 (없는 경우 기존 유지)
   - 결제 영수증(상세) 화면 디자인 확인
     * Modal인지 BottomSheet인지 확인
     * 정보 표시 레이아웃
     * 버튼 스타일
     * 취소 내역 표시 방식 (있는 경우)

2. 색상 및 타이포그래피 매핑
   - 피그마에서 사용된 색상 → commons/constants/color.ts의 Colors 토큰 매핑
   - 피그마에서 사용된 폰트 → commons/constants의 Typography 토큰 매핑
   - 간격(spacing) → commons/constants의 Spacing 토큰 매핑

3. 컴포넌트 구조 설계
   - 피그마 디자인의 컴포넌트 구조 파악
   - 공통 컴포넌트 활용 계획 수립
   - 커스텀 컴포넌트가 필요한 부분 파악

4. styles.ts 수정
   - 피그마 디자인 기반으로 모든 스타일 재작성
   - 색상 토큰, 타이포 토큰, Spacing 토큰 사용
   - 하드코딩된 값 0건
   - 인라인 스타일 0건

5. index.tsx 수정
   - 피그마 디자인의 레이아웃 구조 반영
   - 기존 로직 유지 (필터링, 목 데이터 사용, 모달/바텀시트 표시 등)
   - 공통 컴포넌트 활용
   - 불필요한 코드 제거

6. types.ts 수정 (필요시)
   - 새로운 타입이 필요한 경우만 추가
   - 기존 타입 최대한 유지

7. mockData.ts 수정 (필요시)
   - 피그마 디자인에 맞게 데이터 추가/수정
   - 기존 데이터 구조 유지

구현 가이드

1. 결제 내역 목록 화면
   - 피그마 디자인의 헤더 스타일 따르기
   - 필터 탭이 있으면 디자인대로 구현 (전체/완료/취소 등)
   - 결제 카드 디자인 정확히 구현
     * 카드 배경색, 테두리, 라운드 처리
     * 주문번호, 금액, 결제수단, 날짜 등 정보 배치
     * 상태 뱃지 스타일
     * 화살표 아이콘 (있는 경우)
   - 빈 화면 디자인 (피그마에 있으면 구현, 없으면 기존 유지)

2. 결제 영수증(상세) 화면
   - Modal인지 BottomSheet인지 피그마 디자인 확인 후 선택
   - 정보 레이아웃 디자인대로 구현
     * 타이틀
     * 라벨-값 쌍 레이아웃
     * 구분선 스타일
     * 취소 내역 섹션 (있는 경우)
   - 영수증 보기 버튼 스타일
     * Button 컴포넌트 사용
     * variant, size는 피그마 디자인에 맞게 선택

3. 반응형 고려
   - 피그마 디자인의 여백, 패딩, 간격 정확히 적용
   - Spacing 토큰 사용

4. 기존 기능 유지
   - 필터링 로직 유지 (전체/완료/취소)
   - 목 데이터 사용 유지 (MOCK_PAYMENT_LIST, MOCK_PAYMENT_DETAILS)
   - 카드 클릭 → 상세 모달/바텀시트 표시
   - 영수증 보기 버튼 → Linking.openURL
   - 날짜/통화 포맷팅 함수 유지

주의사항

1. 피그마 디자인 우선
   - 피그마 디자인과 기존 구현이 다르면 피그마를 따를 것
   - 피그마에 명시되지 않은 부분은 기존 구현 유지

2. 기존 로직 보존
   - UI만 변경하고 데이터 처리 로직은 유지
   - 목 데이터 사용 방식 유지
   - usePaymentHistory hook은 수정 금지

3. 토큰 시스템 준수
   - 색상: Colors 토큰만 사용
   - 타이포: Typography 토큰만 사용
   - 간격: Spacing 토큰만 사용
   - 하드코딩 절대 금지

4. 공통 컴포넌트 활용
   - Button, Modal, BottomSheet 최대한 활용
   - Props로 스타일 조정
   - 공통 컴포넌트 직접 수정 금지

5. 인라인 스타일 금지
   - 모든 스타일은 styles.ts에 정의
   - style={{...}} 사용 금지
