핵심요구사항) 음성 녹음 기능 구현
            1) 유저시나리오
                1. "녹음하기" 버튼 클릭
                2. 마이크 권한 요청 (처음 한 번만)
                3. 녹음 시작
                4. 녹음 시간 실시간 표시 (00:00 형식)
                5. "중지" 버튼으로 녹음 종료
                6. 녹음된 파일 URI를 voice 필드에 저장
                7. 녹음된 파일 정보 표시 (파일명, 시간)

            2) 기술 요구사항
                - expo-av의 Audio.Recording 사용
                - 권한 요청: Audio.requestPermissionsAsync()
                - 녹음 품질 설정:
                  - Android: Audio.AndroidAudioEncoder.AAC
                  - iOS: Audio.IOSAudioQuality.HIGH
                  - SampleRate: 44100
                  - NumberOfChannels: 1 (모노)
                  - BitRate: 128000
                - 최대 녹음 시간: 3분 (180초)
                - 3분 도달 시 자동 중지 및 알림

            3) 녹음 파일 저장
                - 녹음된 파일 URI를 react-hook-form의 voice 필드에 저장
                - setValue('voice', recordingUri) 사용
                - watch('voice')로 현재 상태 확인
                - 녹음 시간 정보도 함께 저장 (duration)

                - 파일 크기 제한: 10MB

                - watch('voice')로 현재 상태 확인
