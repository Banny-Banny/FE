Button 컴포넌트 사용 가이드)

1. Button Props 인터페이스:
   interface ButtonProps {
     label: string;                                      // 버튼 텍스트 (필수)
     variant?: 'primary' | 'secondary' | 'outline';      // 버튼 스타일 (선택, 기본값: 'primary')
     size?: 'L' | 'M' | 'S';                             // 버튼 크기 (선택, 기본값: 'L')
     icon?: string;                                       // 아이콘 이름 (선택)
     iconPosition?: 'left' | 'only';                      // 아이콘 위치 (선택, 기본값: 'left')
     fullWidth?: boolean;                                 // 전체 너비 (선택, 기본값: true)
     disabled?: boolean;                                  // 비활성화 (선택, 기본값: false)
     onPress: () => void;                                 // 클릭 이벤트 (필수)
   }

2. 취소/저장 버튼 사용 예시:
   <View style={styles.buttonContainer}>
     <Button
       label="취소"
       variant="secondary"
       size="M"
       fullWidth={false}
       disabled={isSubmitting}
       onPress={handleCancel}
     />
     <Button
       label={isSubmitting ? '저장 중...' : '저장'}
       variant="primary"
       size="M"
       fullWidth={false}
       disabled={isSubmitting}
       onPress={handleSave}
     />
   </View>

3. 추가 버튼 사용 예시:
   <Button
     label={isPickingImage ? '선택 중...' : '사진 추가'}
     variant="outline"
     size="S"
     icon="add-line"
     disabled={isPickingImage || currentPhotos.length >= 5}
     onPress={handleAddPhoto}
   />

4. 기존 코드와 비교:
   기존:
   <Pressable
     style={styles.cancelButton}
     onPress={handleCancel}
     disabled={isSubmitting}>
     <Text style={styles.cancelButtonText}>취소</Text>
   </Pressable>

   변경 후:
   <Button
     label="취소"
     variant="secondary"
     size="M"
     fullWidth={false}
     disabled={isSubmitting}
     onPress={handleCancel}
   />
