핵심요구사항) 데이터 검증 기능 구현
            1) 유저시나리오
                1. 사용자가 "저장" 버튼 클릭
                2. 폼 데이터 검증 실행
                3. 검증 통과 시 제출 진행
                4. 검증 실패 시 에러 메시지 표시
                5. 제출 완료 후 바텀시트 닫기

            2) 검증 규칙
                - 최소 하나의 콘텐츠 필수 (텍스트, 사진, 음악, 동영상 중 1개 이상)

                - 사진: 최대 5개 제한
                - 음악: 최대 1개 제한
                - 동영상: 최대 1개 제한
                - 파일 크기 검증 (선택사항)
                  - 사진: 각 5MB 이하
                  - 동영상: 50MB 이하
                  - 음악: 10MB 이하

            3) 검증 실패 처리
                - Alert로 명확한 에러 메시지 표시
                - 어떤 항목이 문제인지 구체적으로 안내
                - 사용자가 수정할 수 있도록 바텀시트는 유지

추가요구사항) URI를 File/Blob으로 변환
            1) React Native 환경 고려
                - expo-file-system 사용 고려
                - fetch API로 URI에서 Blob 생성
                - 파일명 추출 또는 생성

            2) 변환 로직
                ```typescript
                async function uriToBlob(uri: string): Promise<Blob> {
                  const response = await fetch(uri);
                  const blob = await response.blob();
                  return blob;
                }

                async function uriToFile(uri: string, name: string, type: string): Promise<File> {
                  const blob = await uriToBlob(uri);
                  return new File([blob], name, { type });
                }
                ```

            3) 파일명 생성
                - 타임스탬프 사용: `photo_${Date.now()}.jpg`
                - 또는 원본 파일명 추출: `uri.split('/').pop()`
