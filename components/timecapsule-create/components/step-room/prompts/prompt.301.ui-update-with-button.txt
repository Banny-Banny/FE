Button 컴포넌트 사용 가이드)

1. Button Props 인터페이스:
   interface ButtonProps {
     label: string;                                      // 버튼 텍스트 (필수)
     variant?: 'primary' | 'secondary' | 'outline';      // 버튼 스타일 (선택, 기본값: 'primary')
     size?: 'L' | 'M' | 'S';                             // 버튼 크기 (선택, 기본값: 'L')
     icon?: string;                                       // 아이콘 이름 (선택)
     iconPosition?: 'left' | 'only';                      // 아이콘 위치 (선택, 기본값: 'left')
     fullWidth?: boolean;                                 // 전체 너비 (선택, 기본값: true)
     disabled?: boolean;                                  // 비활성화 (선택, 기본값: false)
     onPress: () => void;                                 // 클릭 이벤트 (필수)
   }

2. 사용 예시:
   <Button
     label="타임캡슐 묻기"
     variant="primary"
     size="L"
     disabled={!isSubmitEnabled || isSubmittingCapsule}
     onPress={handleSubmitButtonPress}
   />

3. 로딩 상태 표시:
   - label에 조건부로 텍스트 변경:
     label={isSubmittingCapsule ? '제출 중...' : '타임캡슐 묻기'}
   - disabled에 로딩 상태 포함:
     disabled={!isSubmitEnabled || isSubmittingCapsule}

4. 기존 코드와 비교:
   기존:
   <TouchableOpacity
     style={[styles.submitButton, (!isSubmitEnabled || isSubmittingCapsule) && { opacity: 0.5 }]}
     disabled={!isSubmitEnabled || isSubmittingCapsule}
     onPress={handleSubmitButtonPress}>
     <Text style={styles.submitButtonText}>
       {isSubmittingCapsule ? '제출 중...' : '타임캡슐 묻기'}
     </Text>
   </TouchableOpacity>

   변경 후:
   <Button
     label={isSubmittingCapsule ? '제출 중...' : '타임캡슐 묻기'}
     variant="primary"
     size="L"
     disabled={!isSubmitEnabled || isSubmittingCapsule}
     onPress={handleSubmitButtonPress}
   />
