interface Participant {
  id: string;                     // 참여자 고유 ID (예: 'user-001')

  content?: {
    text?: string;                // 텍스트 내용
    images?: string[];            // 이미지 URL 배열
    voiceRecording?: string;      // 음성 녹음 URL
  };
}

핵심요구사항-프로그레스바) 진행 상황 프로그레스바 구현

1. 프로그레스바 표시 위치
   - 정보 카드와 참여자 목록 사이
   - 화면 상단에 고정되어 스크롤 시에도 보임

2. 프로그레스바 구성 요소
   - 레이블: "진행 상황" 텍스트
   - 진행 값: "완료 인원 / 전체 인원" 형태 (예: "2/4")
   - 프로그레스 바: 퍼센티지 기반 채워지는 바
   - 색상: 완료된 부분은 강조 색상, 나머지는 회색

3. 계산 로직
   - 완료 인원: status === 'completed'인 참여자 수
   - 전체 인원: name이 빈 문자열이 아닌 참여자 수 (실제 입장한 사람만 카운트)
   - 진행률: (완료 인원 / 전체 인원) × 100
   - 예시:
     - 4명 중 2명 완료: 2/4 = 50%
     - 2명 중 1명 완료: 1/2 = 50%
     - 1명 중 0명 완료: 0/1 = 0%
     - 4명 모두 완료: 4/4 = 100%

4. 실시간 업데이트
   - 참여자가 작성 완료 시 즉시 프로그레스바 업데이트
   - 새로운 참여자 입장 시 전체 인원 증가 및 퍼센티지 재계산
   - useMemo를 사용하여 불필요한 재계산 방지

5. UI 표시
   - 0% 상태: 빈 프로그레스바 표시
   - 1-99% 상태: 부분적으로 채워진 프로그레스바
   - 100% 상태: 완전히 채워진 프로그레스바 + 시각적 강조 (색상 변경 등)

6. 애니메이션 (선택사항)
   - 진행률 변경 시 부드러운 transition 효과
   - 100% 달성 시 축하 애니메이션 (선택사항)

7. 예시 코드 구조
   ```typescript
   // 진행 상황 계산
   const completedCount = participants.filter(p => p.status === 'completed').length;
   const totalCount = participants.filter(p => p.name !== '').length;
   const progressPercentage = totalCount > 0 ? (completedCount / totalCount) * 100 : 0;

   // JSX
   <View style={styles.progressSection}>
     <View style={styles.progressHeader}>
       <Text style={styles.progressLabel}>진행 상황</Text>
       <Text style={styles.progressValue}>{completedCount}/{totalCount}</Text>
     </View>
     <View style={styles.progressBarContainer}>
       <View style={[styles.progressBarFill, { width: `${progressPercentage}%` }]} />
     </View>
   </View>
   ```

8. 스타일 요구사항
   - progressSection: 전체 섹션 컨테이너
   - progressHeader: 레이블과 값이 좌우로 배치
   - progressLabel: "진행 상황" 텍스트 스타일
   - progressValue: "2/4" 형태의 값 스타일
   - progressBarContainer: 프로그레스바 배경 (회색)
   - progressBarFill: 채워지는 부분 (강조 색상)

9. 접근성
   - 프로그레스바 진행률을 음성으로 읽을 수 있도록 accessibilityLabel 제공
   - 예: "진행 상황: 4명 중 2명 완료, 50퍼센트"

- error: Error | null
- progress: { completed: number; total: number; percentage: number }

   - progress.percentage를 width로 적용

   - 실시간 업데이트 확인
     - 참여자 작성 완료 시 즉시 반영

   - 100% 달성 시 시각적 피드백
     - 프로그레스바 색상 변경 (선택사항)
     - 타임캡슐 묻기 버튼 활성화

   - canEdit(participant.id) 체크
   - 본인 것만 클릭 가능
