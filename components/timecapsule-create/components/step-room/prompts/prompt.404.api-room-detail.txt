API응답명세) 백엔드 응답 구조

대기실 상세 조회 API
엔드포인트: GET /api/capsules/step-rooms/:capsuleId
인증: Bearer {JWT_TOKEN} (필수)
Content-Type: application/json

Path Parameter:
- capsuleId: 캡슐 ID (UUID) - 1단계 API에서 추출한 capsule_id

성공 응답 (200 OK):

  "deadline": "2026-01-06T08:27:08.324Z",
  "status": "WAITING",
  "slots": [
    {
      "slot_number": 1,
      "user_id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
      "is_host": true,

      "nickname": "홍길동"

    {
      "slot_number": 2,
      "user_id": "b2c3d4e5-f6a7-8901-bcde-f12345678901",

      "nickname": "김철수"

에러 응답:
- 400 Bad Request: 잘못된 UUID 형식
- 401 Unauthorized: JWT 토큰 없음 또는 유효하지 않음
- 403 Forbidden: 참여자가 아닌 사용자의 접근
- 404 Not Found: 존재하지 않는 capsuleId
- 500 Internal Server Error: 서버 내부 오류

주의:
- 응답 구조는 RoomDetailResponse 타입 (snake_case)
- slots[] 배열은 slot_number 순서대로 정렬됨
- 첫 번째 슬롯(slot_number=1)이 방장
- user_id가 null이면 아직 배정되지 않은 슬롯

응답필드설명) 각 필드의 의미 및 활용

1. room_id (string, UUID)
   - 대기실 고유 ID
   - capsuleId와 동일한 값

2. capsule_name (string)
   - 캡슐 이름
   - UI 정보 카드에 표시

3. open_date (string, ISO 8601)
   - 캡슐 개봉 날짜
   - 예: "2026-01-12T08:27:08.324Z"

4. deadline (string, ISO 8601)
   - 작성 마감 시한
   - 예: "2026-01-06T08:27:08.324Z"

5. status (string)
   - 대기실 상태
   - 값: "WAITING" | "COMPLETED" | "EXPIRED"

6. slots[] (array)
   - 참여자 슬롯 배열
   - slot_number 순서대로 정렬됨
   - 각 슬롯 정보:
     - slot_number: 슬롯 번호 (1부터 시작)
     - user_id: 사용자 ID (UUID, null이면 아직 배정되지 않음)
     - is_host: 방장 여부
     - status: 슬롯 상태 ("ACCEPTED" | "PENDING")
     - nickname: 참여자 닉네임 (null이면 아직 배정되지 않음)

   - GET /api/capsules/step-rooms/:capsuleId 호출
   - Authorization: Bearer {token} 헤더 포함 (apiClient가 자동 처리)
   - 응답을 그대로 반환 (snake_case 유지)
   - 에러 처리 및 예외 던지기

구현 예시:
```typescript
import { apiClient } from '@/utils/apiClient';
import type { RoomDetailResponse } from '../types';

/**
 * 대기실 상세 조회 API (참여자 슬롯 정보 포함)
 * @param capsuleId 캡슐 ID (UUID)
 * @returns 대기실 상세 정보 (슬롯 정보 포함)
 * @throws 400: 잘못된 UUID 형식
 * @throws 401: JWT 토큰 없음 또는 유효하지 않음
 * @throws 403: 참여자가 아닌 사용자의 접근
 * @throws 404: 존재하지 않는 capsuleId
 * @throws 500: 서버 내부 오류
 */
export async function getRoomDetail(capsuleId: string): Promise<RoomDetailResponse> {
  try {
    console.log('🔄 [API] 대기실 상세 조회 시작 - capsuleId:', capsuleId);

    // apiClient는 자동으로 JWT 토큰을 헤더에 포함시킴
    const response = await apiClient.get<RoomDetailResponse>(
      `/api/capsules/step-rooms/${capsuleId}`
    );

    console.log('✅ [API] 대기실 상세 조회 성공:', response.data);
    return response.data;
  } catch (error: any) {
    if (error.response?.status === 400) {
      console.error('❌ [API] 잘못된 UUID 형식 (400)');
      throw new Error('잘못된 캡슐 ID 형식입니다.');
    }
    if (error.response?.status === 401) {
      console.error('❌ [API] 인증 실패 (401)');
      throw new Error('인증이 필요합니다. 로그인 후 다시 시도해주세요.');
    }
    if (error.response?.status === 403) {
      console.error('❌ [API] 권한 없음 (403)');
      throw new Error('참여자만 조회할 수 있습니다.');
    }
    if (error.response?.status === 404) {
      console.error('❌ [API] 존재하지 않는 capsuleId (404)');
      throw new Error('대기실을 찾을 수 없습니다.');
    }
    if (error.response?.status === 500) {
      console.error('❌ [API] 서버 내부 오류 (500)');
      throw new Error('일시적인 오류가 발생했습니다. 잠시 후 다시 시도해주세요.');
    }
    console.error('❌ [API] 대기실 상세 조회 실패:', error.message);
    throw new Error(`API 호출 실패: ${error.response?.status || 'Network Error'}`);
  }
}
```

```typescript
import AsyncStorage from '@react-native-async-storage/async-storage';
import { getRoomDetail } from '../api/capsule';
import { DEFAULT_EMOJI, EMPTY_SLOT_EMOJI, PARTICIPANT_STATUS } from '../constants';
import { getUserFromToken } from '@/utils/auth';
import { STORAGE_KEYS } from '@/commons/constants/storage';
import type { Participant } from '../types';

export function useParticipants({
  capsuleId,
  maxParticipants,
}: UseParticipantsParams): UseParticipantsReturn {
  const [participants, setParticipants] = useState<Participant[]>([]);
  const [isLoading, setIsLoading] = useState<boolean>(true);
  const [error, setError] = useState<Error | null>(null);

  useEffect(() => {
    async function fetchParticipants() {
      // capsuleId가 없으면 아무것도 하지 않음 (로딩 상태 유지)
      if (!capsuleId) {
        return;
      }

      setIsLoading(true);
      setError(null);

      try {
        // ⭐ API 호출: 대기실 상세 조회
        console.log('🔄 [useParticipants] 참여자 슬롯 정보 조회 시작 - capsuleId:', capsuleId);
        const roomDetail = await getRoomDetail(capsuleId);

        // 현재 사용자 ID 가져오기 (본인 여부 판단용)
        const token = await AsyncStorage.getItem(STORAGE_KEYS.ACCESS_TOKEN);
        const currentUser = token ? getUserFromToken(token) : null;
        const currentUserId = currentUser?.id || null;

        // slots[] 배열을 Participant[] 형식으로 변환
        const participantsList: Participant[] = [];

        // 실제 슬롯 정보 변환
        for (const slot of roomDetail.slots) {
          if (slot.user_id && slot.nickname) {
            // 배정된 슬롯
            const isMe = slot.user_id === currentUserId;
            participantsList.push({
              id: slot.user_id,
              name: slot.nickname,
              emoji: DEFAULT_EMOJI, // 기본 이모지 (추후 사용자 프로필에서 가져올 수 있음)
              status:
                slot.status === 'ACCEPTED'
                  ? PARTICIPANT_STATUS.PENDING
                  : PARTICIPANT_STATUS.WAITING,
              isHost: slot.is_host,
              isMe,
              // 작성 완료 여부는 별도 API로 확인 필요 (현재는 PENDING으로 설정)
              // 추후 콘텐츠 저장 API 응답에서 COMPLETED 상태로 업데이트
            });
          }
        }

        // 빈 슬롯 추가 (maxParticipants까지)
        const filledSlots = roomDetail.slots.length;
        for (let i = filledSlots; i < maxParticipants; i++) {
          participantsList.push({
            id: `slot-${i + 1}`,
            name: '',
            emoji: EMPTY_SLOT_EMOJI,
            status: PARTICIPANT_STATUS.WAITING,
          });
        }

        setParticipants(participantsList);
        console.log('✅ [useParticipants] 참여자 슬롯 정보 조회 성공:', participantsList);
      } catch (err) {
        console.warn('⚠️ [useParticipants] API 호출 실패, 목데이터 사용:', err);
        setError(err instanceof Error ? err : new Error('API 호출 실패'));
        // 목데이터로 폴백
        setParticipants(mockParticipants);
      } finally {
        setIsLoading(false);
      }
    }

    fetchParticipants();
  }, [capsuleId, maxParticipants]);

  return {
    participants,
    myParticipant,
    isLoading,
    error,
    updateStatus,
    saveContent,
    canEdit,
  };
}
```

   - 원인: 인터넷 연결 끊김, 서버 다운
   - 대응: 목데이터 폴백
   - 메시지: "네트워크 연결을 확인해주세요."

에러 처리 우선순위:
1. 목데이터로 폴백 (앱 사용 가능하도록)
2. 콘솔 로그로 에러 기록 (개발자 디버깅용)
3. 사용자 피드백 제공 (토스트, 모달 등) (선택사항)

==============================================

주의사항)

1. API 응답 형식 준수
   - 백엔드가 snake_case로 응답
   - 프론트엔드는 snake_case를 그대로 사용 (프로젝트 일관성)
   - 타입 불일치 방지

2. 슬롯 상태 매핑
   - ACCEPTED → pending (작성 중/미작성)
   - PENDING → waiting (아직 입장 안함)
   - 작성 완료 여부는 별도 API로 확인 필요

3. 본인 여부 판단
   - user_id와 현재 사용자 ID 비교
   - AsyncStorage에서 토큰 추출 후 getUserFromToken으로 사용자 ID 가져오기
   - isMe 필드 설정

4. 빈 슬롯 처리
   - maxParticipants까지 빈 슬롯 추가
   - name: '', emoji: EMPTY_SLOT_EMOJI, status: WAITING

5. 목데이터 폴백 전략
   - API 호출 실패 시 앱이 멈추지 않도록
   - 개발 환경에서도 정상 작동
   - 프로덕션에서는 에러 로깅 필수

6. TypeScript 타입 안정성
   - API 응답 타입 명시 (RoomDetailResponse, Slot, snake_case)
   - any 사용 금지

7. 에러 처리
   - try-catch 블록 필수
   - 에러 로깅 (console.warn)
   - 사용자 피드백 (선택사항)

8. ⭐ 인증 필수
   - Bearer {JWT_TOKEN} 헤더 필수
   - apiClient가 자동으로 토큰을 헤더에 포함시킴
   - 401 에러 시 로그인 페이지로 리다이렉트 고려

9. ⭐ capsuleId 의존성
   - capsuleId가 없으면 API 호출하지 않음
   - useEffect의 의존성 배열에 capsuleId 포함
   - capsuleId가 설정될 때까지 대기
