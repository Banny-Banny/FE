API응답명세) 백엔드 응답 구조

대기실 설정값 조회 API
엔드포인트: GET /api/capsules/step-rooms/:capsuleId/settings
인증: Bearer {JWT_TOKEN} (필수)
Content-Type: application/json

Path Parameter:
- capsuleId: 캡슐 ID (UUID) - 1단계 API에서 추출한 capsule_id

성공 응답 (200 OK):
{
  "room_id": "3dc6c7ee-f26f-41b7-aee3-1daaac34a46e",
  "capsule_name": "나의 타임캡슐",
  "open_date": "2026-01-12",
  "max_participants": 2,
  "max_images_per_person": 3,
  "has_music": true,
  "has_video": false
}

에러 응답:
- 400 Bad Request: 잘못된 UUID 형식
- 401 Unauthorized: JWT 토큰 없음 또는 유효하지 않음
- 404 Not Found: 존재하지 않는 capsuleId 또는 주문 정보 없음
- 500 Internal Server Error: 서버 내부 오류

주의:
- 응답 구조는 RoomSettingsResponse 타입 (snake_case)
- capsule_name은 orders에서 설정한 정확한 제목
- max_images_per_person은 주문의 총 사진 개수(photoCount) ÷ 인원수(headcount)로 계산됨

응답필드설명) 각 필드의 의미 및 활용

1. room_id (string, UUID)
   - 대기실 고유 ID
   - capsuleId와 동일한 값

2. capsule_name (string)
   - 방장이 설정한 캡슐 이름 (orders에서 설정한 제목)

3. open_date (string, YYYY-MM-DD)
   - 캡슐 개봉 날짜
   - UI 정보 카드에 표시
   - 예: "2026-01-12"

4. max_participants (number)
   - 총 참여 가능 인원 수
   - UI 정보 카드에 표시
   - 예: 2

5. max_images_per_person (number)
   - 1인당 최대 업로드 가능 사진 개수
   - 업로드 UI에서 사진 입력 필드 개수 제한
   - 계산식: 주문의 총 사진 개수(photoCount) ÷ 인원수(headcount)
   - 예: 3 (1인당 최대 3장)

6. has_music (boolean)
   - 음성 녹음 기능 활성화 여부
   - true: 음성 녹음 버튼 표시
   - false: 음성 녹음 버튼 숨김
   - 예: true

7. has_video (boolean)
   - 동영상 업로드 기능 활성화 여부
   - true: 동영상 업로드 버튼 표시
   - false: 동영상 업로드 버튼 숨김

구현가이드-1) API 호출 함수 작성

파일: components/timecapsule-create/components/step-room/api/capsule.ts

목적:
- 대기실 설정값 조회 API 호출 함수 제공
- GET /api/capsules/step-rooms/:capsuleId/settings 호출
- 에러 처리
- 재사용 가능한 API 함수 제공
- ⭐ JWT 토큰 인증 처리

기능:
1. getRoomSettings(capsuleId: string): Promise<RoomSettingsResponse>
   - GET /api/capsules/step-rooms/:capsuleId/settings 호출
   - Authorization: Bearer {token} 헤더 포함 (apiClient가 자동 처리)
   - 응답을 그대로 반환 (snake_case 유지)
   - 에러 처리 및 예외 던지기

구현 예시:
```typescript
import { apiClient } from '@/utils/apiClient';
import type { RoomSettingsResponse } from '../types';

/**
 * 대기실 설정값 조회 API
 * @param capsuleId 캡슐 ID (UUID) - 1단계에서 추출한 capsule_id
 * @returns 대기실 설정값 (snake_case)
 * @throws 400: 잘못된 UUID 형식
 * @throws 401: JWT 토큰 없음 또는 유효하지 않음
 * @throws 404: 존재하지 않는 capsuleId 또는 주문 정보 없음
 * @throws 500: 서버 내부 오류
 */
export async function getRoomSettings(capsuleId: string): Promise<RoomSettingsResponse> {
  try {
    console.log('🔄 [API] 대기실 설정값 조회 시작 - capsuleId:', capsuleId);

    // apiClient는 자동으로 JWT 토큰을 헤더에 포함시킴
    const response = await apiClient.get<RoomSettingsResponse>(
      `/api/capsules/step-rooms/${capsuleId}/settings`
    );

    console.log('✅ [API] 대기실 설정값 조회 성공:', response.data);
    return response.data;
  } catch (error: any) {
    if (error.response?.status === 400) {
      console.error('❌ [API] 잘못된 UUID 형식 (400)');
      throw new Error('잘못된 캡슐 ID 형식입니다.');
    }
    if (error.response?.status === 401) {
      console.error('❌ [API] 인증 실패 (401)');
      throw new Error('인증이 필요합니다. 로그인 후 다시 시도해주세요.');
    }
    if (error.response?.status === 404) {
      console.error('❌ [API] 존재하지 않는 capsuleId (404)');
      throw new Error('대기실 또는 주문 정보를 찾을 수 없습니다.');
    }
    if (error.response?.status === 500) {
      console.error('❌ [API] 서버 내부 오류 (500)');
      throw new Error('일시적인 오류가 발생했습니다. 잠시 후 다시 시도해주세요.');
    }
    console.error('❌ [API] 대기실 설정값 조회 실패:', error.message);
    throw new Error(`API 호출 실패: ${error.response?.status || 'Network Error'}`);
  }
}
```

   - getRoomSettings의 capsule_name 우선 사용 (orders에서 설정한 정확한 제목)

3. 에러 처리

구현 예시:
```typescript
// 1단계에서 capsuleId 추출 후
const extractedCapsuleId = roomData.capsule_id;
setCapsuleId(extractedCapsuleId);

// ⭐ 2단계: 대기실 설정값 조회
try {
  console.log('🔄 [useRoomData] 대기실 설정값 조회 시작 - capsuleId:', extractedCapsuleId);
  const settingsData = await getRoomSettings(extractedCapsuleId);

  // CreateRoomResponse의 추가 정보와 병합
  // getRoomSettings의 capsule_name이 orders에서 설정한 정확한 제목이므로 우선 사용
  const mergedSettings: RoomSettingsResponse = {
    ...settingsData,
    room_id: roomData.capsule_id,
    // capsule_name은 getRoomSettings에서 가져온 값 사용 (orders에서 설정한 제목)
    open_date: roomData.open_date.split('T')[0], // ISO 8601에서 YYYY-MM-DD 추출
    max_participants: roomData.max_participants,
  };
  setRoomSettings(mergedSettings);

  console.log('✅ [useRoomData] 대기실 설정값 조회 성공:', mergedSettings);
} catch (settingsError) {
  console.warn('⚠️ [useRoomData] 설정값 조회 실패, 기본값 사용:', settingsError);
  // 설정값 조회 실패 시 CreateRoomResponse만으로 구성
  const fallbackSettings: RoomSettingsResponse = {
    room_id: roomData.capsule_id,
    capsule_name: roomData.title, // fallback: CreateRoomResponse의 title 사용
    open_date: roomData.open_date.split('T')[0],
    max_participants: roomData.max_participants,
    max_images_per_person: 3, // 기본값
    has_music: false, // 기본값
    has_video: false, // 기본값
  };
  setRoomSettings(fallbackSettings);
}
```
