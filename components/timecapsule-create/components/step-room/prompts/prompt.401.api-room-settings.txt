구현가이드-1) API 호출 함수 작성

파일: utils/api/capsule.ts

목적:
- 대기실 설정값 조회 API 호출
- 에러 처리
- 재사용 가능한 API 함수 제공

기능:
1. fetchRoomSettings(capsuleId: string): Promise<RoomSettingsResponse>
   - GET /api/capsules/step-rooms/:capsuleId/settings 호출
   - 응답을 그대로 반환 (snake_case 유지, 프로젝트 일관성)
   - 에러 처리 및 예외 던지기

구현 예시:
```typescript
import { RoomSettingsResponse } from '@/components/timecapsule-create/components/step-room/types';

// .env에 이미 설정된 API URL 사용
const API_BASE_URL = process.env.EXPO_PUBLIC_API_BASE_URL || 'http://localhost:3000';

/**
 * 대기실 설정값 조회 API
 * @param capsuleId 캡슐 ID (UUID)
 * @returns 대기실 설정값 (snake_case)
 * @throws 404: 존재하지 않는 capsuleId 또는 주문 정보 없음
 * @throws 500: 서버 내부 오류
 */
export async function fetchRoomSettings(capsuleId: string): Promise<RoomSettingsResponse> {
  try {
    const response = await fetch(
      `${API_BASE_URL}/api/capsules/step-rooms/${capsuleId}/settings`,
      {
        method: 'GET',
        headers: {
          'Content-Type': 'application/json',
        },
      }
    );

    if (!response.ok) {
      if (response.status === 404) {
        throw new Error('대기실 또는 주문 정보를 찾을 수 없습니다.');
      }
      throw new Error(`API 호출 실패: ${response.status}`);
    }

    const data: RoomSettingsResponse = await response.json();
    return data;
  } catch (error) {
    console.error('대기실 설정값 조회 실패:', error);
    throw error;
  }
}
```

   - 1순위: API 데이터 (snake_case)
   - 2순위 (에러 시): 목데이터 (snake_case)
2. RoomData 변환: snake_case → camelCase (내부 변환만, API 응답은 그대로)
3. 에러 로깅
4. 사용자에게 에러 표시 (선택사항)

구현 예시:
```typescript
import { useState, useEffect } from 'react';
import { fetchRoomSettings } from '@/utils/api/capsule';
import { RoomSettingsResponse } from '../types';
import { mockRoomData } from '../constants';

export function useRoomData(capsuleId: string) {
  const [roomSettings, setRoomSettings] = useState<RoomSettingsResponse | null>(null);
  const [isLoading, setIsLoading] = useState(true);
  const [error, setError] = useState<Error | null>(null);

  useEffect(() => {
    async function loadRoomData() {
      setIsLoading(true);
      setError(null);

      try {
        // API 호출 시도 (snake_case 그대로 반환)
        const data = await fetchRoomSettings(capsuleId);
        setRoomSettings(data);

        // RoomData 변환 (내부 변환만, snake_case → camelCase)
        setRoomData({
          capsuleId: data.room_id,
          capsuleName: data.capsule_name,
          openDate: data.open_date,
          maxParticipants: data.max_participants,
          // ...
        });
      } catch (err) {
        console.warn('API 호출 실패, 목데이터 사용:', err);
        setError(err instanceof Error ? err : new Error('Unknown error'));

        // 목데이터로 폴백 (snake_case)
        setRoomSettings(mockRoomData);
      } finally {
        setIsLoading(false);
      }
    }

    if (capsuleId) {
      loadRoomData();
    }
  }, [capsuleId]);

  return {
    roomSettings,
    isLoading,
    error,
  };
}
```
