- TossPayment 컴포넌트를 래핑하여 사용
- info 페이지에서 전달받은 orderData, formData를 route params로 수신
- 웹 환경에서 결제 리다이렉트 시 sessionStorage 복원
- 결제 완료 후 room 페이지로 이동

구현 예시 - 비즈니스 로직 (components/timecapsule-create/pages/payment/index.tsx):
```typescript
import { ROUTES } from '@/commons/constants';
import { Spinner } from '@/commons/components/spinner';
import TossPayment from '@/components/toss-payments';
import { CreateOrderResponse } from '@/components/timecapsule-create/components/step-info/api/types/order';
import { StepInfoFormData } from '@/components/timecapsule-create/components/step-info/types';
import { useLocalSearchParams, useRouter } from 'expo-router';
import React, { useEffect, useMemo, useState } from 'react';
import { Platform, View } from 'react-native';

/**
 * 타임캡슐 생성 - 결제 페이지
 */
export default function TimeCapsuleCreatePayment() {
  const router = useRouter();
  const params = useLocalSearchParams();
  const [isRedirecting, setIsRedirecting] = useState(false);

  // useMemo로 초기 데이터 계산 최적화
  const initialData = useMemo(() => {
    // 1순위: route params (일반적인 경우)
    if (params.orderData && params.formData) {
      return {
        orderData: JSON.parse(params.orderData as string) as CreateOrderResponse,
        formData: JSON.parse(params.formData as string) as StepInfoFormData,
      };
    }

    // 2순위: sessionStorage (웹 환경, 결제 리다이렉트 시)
    if (Platform.OS === 'web' && typeof window !== 'undefined') {
      const savedOrderData = sessionStorage.getItem('timecapsule_order_data');
      const savedFormData = sessionStorage.getItem('timecapsule_form_data');
      if (savedOrderData && savedFormData) {
        return {
          orderData: JSON.parse(savedOrderData) as CreateOrderResponse,
          formData: JSON.parse(savedFormData) as StepInfoFormData,
        };
      }
    }

    return null;
  }, [params.orderData, params.formData]);

  const [orderData, setOrderData] = useState<CreateOrderResponse | null>(
    initialData?.orderData || null
  );
  const [formData, setFormData] = useState<StepInfoFormData | null>(
    initialData?.formData || null
  );

  // 웹 환경에서 데이터를 sessionStorage에 저장 (결제 리다이렉트 대비)
  useEffect(() => {
    if (Platform.OS === 'web' && typeof window !== 'undefined' && orderData && formData) {
      sessionStorage.setItem('timecapsule_order_data', JSON.stringify(orderData));
      sessionStorage.setItem('timecapsule_form_data', JSON.stringify(formData));
    }
  }, [orderData, formData]);

  // 데이터가 없으면 info 페이지로 리다이렉트 (로딩 표시)
  useEffect(() => {
    if (!orderData || !formData) {
      setIsRedirecting(true);
      router.replace('/timecapsule/info');
    }
  }, [orderData, formData, router]);

  if (isRedirecting || !orderData || !formData) {
    return <Spinner />;
  }

  const handleBack = () => {
    // sessionStorage 클리어
    if (Platform.OS === 'web' && typeof window !== 'undefined') {
      sessionStorage.removeItem('timecapsule_order_data');
      sessionStorage.removeItem('timecapsule_form_data');
    }
    router.back();
  };

  const handleSubmit = (paymentData: any) => {
    // sessionStorage 클리어
    if (Platform.OS === 'web' && typeof window !== 'undefined') {
      sessionStorage.removeItem('timecapsule_order_data');
      sessionStorage.removeItem('timecapsule_form_data');
    }

    // 대기실 페이지로 이동 (orderId 전달)
    router.push({
      pathname: '/timecapsule/room',
      params: {
        orderId: orderData.order_id,
      },
    });
  };

  return (
    <View style={{ flex: 1 }}>
      <TossPayment
        formData={formData}
        orderData={orderData}
        onBack={handleBack}
        onSubmit={handleSubmit}
      />
    </View>
  );
}
```

데이터 수신:
- route params에서 orderData, formData 수신 (우선순위 1)
- sessionStorage에서 복원 (웹 환경, 결제 리다이렉트 시, 우선순위 2)

데이터 저장:
- 웹 환경에서만 sessionStorage에 저장 (결제 리다이렉트 대비)

데이터 전달:
- orderId만 room 페이지로 전달

뒤로가기:
- info 페이지로 이동 (결제 취소)
- sessionStorage 클리어

구현가이드-데이터전달) 데이터 전달 방식

1. Navigation Params (우선순위 1)
   - info → payment: orderData, formData
   - payment → room: orderId
   - JSON.stringify()로 직렬화
   - JSON.parse()로 복원

2. SessionStorage (웹 전용, 우선순위 2)
   - payment 페이지에서만 사용
   - 결제 리다이렉트 시 데이터 복원용
   - 키:
     - timecapsule_order_data
     - timecapsule_form_data
   - payment 완료 시 클리어
   - payment 뒤로가기 시 클리어

3. 데이터 복원 우선순위
   - 1순위: route params (일반적인 경우)
   - 2순위: sessionStorage (웹 환경, 결제 리다이렉트 시)
   - 데이터 없음: info 페이지로 리다이렉트

구현가이드-웹결제리다이렉트) 웹 환경 결제 리다이렉트 처리

문제 상황:
- 결제 완료 후 ?paymentKey=xxx&orderId=xxx&amount=xxx 파라미터와 함께 리다이렉트
- payment 페이지가 언마운트되면서 상태가 날아감

해결 방안:
1. payment 페이지 마운트 시 orderData와 formData를 sessionStorage에 저장
2. 결제 리다이렉트 후 payment 페이지로 돌아오면 sessionStorage에서 복원
3. TossPayment 컴포넌트가 URL 파라미터를 확인하고 결제 승인 처리
4. 결제 승인 완료 후 room 페이지로 이동
5. room 페이지 이동 시 sessionStorage 클리어

구현 흐름:
```
1. 사용자가 결제 버튼 클릭
   ↓
2. payment 페이지에서 orderData/formData를 sessionStorage에 저장 (웹만)
   ↓
3. TossPayment가 결제창 열기
   ↓
4. 결제 완료 후 /timecapsule/payment?paymentKey=xxx&orderId=xxx&amount=xxx로 리다이렉트
   ↓
5. payment 페이지 컴포넌트 마운트
   - route params 없음
   - sessionStorage에서 orderData/formData 복원
   ↓
```
